# Ozean: الواجهة العامة

هذا المستودع يحتوي على واجهة الموقع فقط:
- `index.html`: الصفحة الكاملة.
- `firebase-bridge.js`: ربط Firebase (تسجيل الدخول وقراءة الأعمال وحفظها).

الكود الخاص بالدفع وقواعد الأمان والدوال موجود في مستودع خاص منفصل، ولا يُنشر هنا.

## التشغيل المحلي
افتح `index.html` في المتصفح، أو شغّل خادماً بسيطاً:
```
npx serve .
```
